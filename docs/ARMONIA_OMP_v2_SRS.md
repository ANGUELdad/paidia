# ARMONIA THASOU

# Operational Management Platform (OMP)

Version: 2.0

## Vision

The system is an Operations Center for residential child care.

## Core Modules

- Dashboard
- Morning Planning
- Afternoon Planning
- Evening Planning
- Daily Call
- Events
- Shopping
- Inventory
- AI Assistant
- Activity Timeline
- Reports

## Planning

### Morning Planning
- Villa
- Limenaria
- Monday-Sunday

### Afternoon Planning
One row per caregiver.
Each cell contains:
- House
- Children
- Activity
- Time
- Location
- Status

### Evening Planning
Same as Morning Planning.

## Filters
- All Houses
- Villa
- Limenaria
- Combined

## AI
AI assists but never performs critical actions without confirmation.

## Inventory
Supports refrigerators, pantry, shopping, transfers, photos and audit trail.

## Validation
Duplicate detection, conflicts, overlapping shifts, inventory validation.

## Reports
Daily, Weekly, Monthly.
