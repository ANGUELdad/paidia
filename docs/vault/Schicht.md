# Schicht

Start and end of a caregiver's shift.

## Gate
Ending a shift requires:
1. Übergabe notiert — handover note for the next shift
2. [[Vorrat|Lager-Check]] — 8-item cycle count

The check is a gate, not a separate errand. That is what makes
"storage checked each shift" actually happen.

## Coverage
Derived warnings, e.g. *only one person after 19:00*, and solo-with-children
flags. See [[Plan]].
