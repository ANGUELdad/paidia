# Vorrat

Stock and shopping, one section with two modes: Bestand / Einkauf.

## Cycle counting
Not all 62 products every shift. A rotating subset of ~8, prioritised by
turnover (ABC). Counts are **blind** — expected quantity is hidden so the
counter is not anchored.

Deviations produce a variance report for the admin.
